A 1024×1024 invented passport spread for the Republic of Sereia, a country that
does not exist: a tide-runner's data page and a coastal work visa with matched
stamps, a tide-fee stamp and one revealing paperwork detail — a crossing permit
conditioned on the tide table.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024, under 1 MiB). The spread is rendered
offline from `design/page.html` into `design/entry.png`; the program copies it,
so a run is deterministic and needs no browser or network.
